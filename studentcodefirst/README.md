# Student Code First

## Overview
This project demonstrates the Code First approach using C#, Entity Framework Core, and SQL Server.

## Technologies Used
- C#
- .NET
- Entity Framework Core
- SQL Server
- Visual Studio

## Features
- Code First database creation
- Student model
- SQL Server LocalDB connection
- Insert student records into the database

## Project Structure
- Models
- Data (DbContext)
- Program.cs
